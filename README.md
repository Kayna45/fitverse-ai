# 🏋️ FitVerse AI - Personalized AI Fitness Coach

> Transform Your Fitness Journey with Artificial Intelligence

FitVerse AI is a full-stack AI-powered fitness platform that provides personalized workout plans, nutrition tracking, AI coaching, fitness analytics, and progress monitoring. The application adapts recommendations based on each user's body metrics and fitness goals to deliver a personalized experience.

# 🛠️ Installation

## Clone Repository

```bash
git clone https://github.com/Kayna45/fitverse-ai.git
```

---

## Install Frontend

```bash
cd client
npm install
npm run dev
```

---

## Install Backend

```bash
cd server
npm install
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000
MONGO_URI=YOUR_MONGODB_URI
JWT_SECRET=YOUR_SECRET_KEY
GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```
